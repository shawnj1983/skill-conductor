# Skill Conductor — examples

## Research a new video

```
Task: scrape today's interview and turn it into house knowledge
Primary: learn-from-internet
Supporting: skill-factory (if a skill should land), conversation-to-skill (close-out)
Skipped: shipping / money skills — no offer asked
Second pass: captions exist; NOTES written; skill or deliberate no logged
```

## User asks for a Cursor rule and a skill that stay together

```
Task: author a paired skill + always-on rule
Primary: create-skill
Supporting: create-rule, skill-conductor (this file — eat your own cooking)
Skipped: implement / TDD — no app code
Second pass: both files exist; rule points at the skill; skill points at the rule
```

## One-line typo in a comment

```
Task: fix a misspelled comment
Primary: (none)
Supporting: (none)
Skipped: catalog — one-step edit, no workflow
Second pass: no missed skill
```

## Ambiguous “build the thing”

```
Task: user said build it; destination unclear
Primary: grill / align skill (house name may differ)
Supporting: whatever the grill hands off (spec, tickets, implement)
Skipped: deploy / publish skills until the user names WHERE
Second pass: did we start coding before alignment? if yes, stop and grill
```

## Two skills both claim the job

```
Task: turn this chat into a skill
Primary: conversation-to-skill (narrower, same-session duty)
Supporting: skill-factory (format / quality bar)
Skipped: create-skill built-in — house factory already covers layout
Second pass: INDEX updated; session log written
```
